A program that writes one funny single-line developer excuse to
`/output/entry.txt`, for the make.fun competition
[Make the AI Judge Laugh: Developer Excuses](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3).

Run it with Python 3:

```
python3 main.py
```

It writes the excuse below to `/output/entry.txt` (or to the path given
as the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The excuse is 97 characters, inside the 1 to 200 gate.

## The excuse

```
It worked on my machine, but my machine has been lying to me for years and I only just found out.
```
